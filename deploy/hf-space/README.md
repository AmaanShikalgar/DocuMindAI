# DocuMind

Ask questions about PDFs and get answers that cite the exact page and passage. Three public
documents are preloaded; PDFs you upload are visible only in your browser.

Source, eval results and docs: https://github.com/AmaanShikalgar/DocuMindAI

This Space is deployed automatically from the GitHub repository's `master` branch.
